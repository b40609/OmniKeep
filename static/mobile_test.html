⚡ 手機端一鍵發送測試

直接在手機端模擬 iOS 捷徑送出請求，驗證手機與主機通訊及兩段式非同步佇列：

📱 iPhone「捷徑」設定 3 步驟

  1. 打開 iPhone 內建「捷徑」App ➔ 點右上角「+」新增。
  2. 點擊下方「(i)」資訊 ➔ 開啟「在分享表單中顯示」（類型選URL與文字）。
  3. 加入動作「取得 URL 的內容」：
    • • URL: 點上方「複製」按鈕貼上
    • • 方法: POST
    • • 標頭: Content-Type: application/json
    • • 標頭: X-API-Key: 請填入自己的 API Key
    • • 要求主體: JSON
    • • 欄位 url = 選擇捷徑輸入（快捷方式輸入）
    • • 欄位 async_mode = True (布林值)
