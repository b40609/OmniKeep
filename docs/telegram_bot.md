# 用 Telegram 收藏：接上你的機器人

把連結傳給你自己的 Telegram 機器人，OmniKeep 就會收下來、讀完，回你一張有摘要和重點的卡片。手機、電腦都能用：在任何 App 看到想留的內容，按「分享」傳給機器人就好。

接上機器人要做三件事：建立機器人、貼上機器人權杖、配對你的帳號。大約 3 分鐘。

---

## 第一步：建立機器人，拿到權杖

1. 在 Telegram 搜尋官方帳號 **`@BotFather`**，開啟對話。
2. 傳 `/newbot`，照它的提示回答兩個問題：
   - **名稱**（name）：顯示在對話上方的名字，隨意取，例如 `My OmniKeep`。
   - **使用者名稱**（username）：機器人的帳號，例如 `my_omnikeep_bot`。規則是 5 到 32 個字元、只能用英文字母、數字與底線、必須以 `bot` 結尾。設定後不能改。
3. 如果 BotFather 說這個使用者名稱不能用（例如已經有人用了），換一個再試，直到它接受。
4. 完成後 BotFather 會給你一串**權杖**（token），樣子是「一串數字、冒號，再接一長串英數字」，例如 `110201543:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw`（這是 Telegram 官方文件的範例，不能用）。

權杖等於這個機器人的密碼：拿到的人就能操作它。不要貼到聊天、截圖或提交到 Git。

---

## 第二步：把權杖貼進 OmniKeep

1. 打開 OmniKeep，按右上角的頭像選單 ›「設定」，左側選「收錄管道」，找到「Telegram」。
2. 把權杖貼到「機器人權杖」。想先確認權杖有效，按「測試機器人」。
3. 按「儲存」。

儲存後機器人立刻連線，不必重新啟動。權杖會加密後才存進資料庫，之後不會再顯示完整內容。

（舊做法：在 `.env` 寫 `TELEGRAM_BOT_TOKEN=...` 仍然有效，但 App 內儲存的值優先。）

---

## 第三步：配對你的帳號

機器人只聽「已綁定的帳號」的話，所以要把你的 Telegram 帳號綁上去。

1. 同一個畫面（設定 › 收錄管道 › Telegram），在「已綁定的帳號」下面按「產生配對連結」。
2. 按「在 Telegram 開啟」。要在手機上綁定的話，按「複製連結」，把連結傳到手機再開。
3. **Telegram 會打開你和機器人的對話，下方有一顆「開始」（Start）按鈕，要按下去。** 只打開連結、沒按「開始」，不會綁定。
4. 成功的話，機器人會回一則訊息，告訴你已經綁定為 OmniKeep 擁有者，並附上你的帳號編號。看到這則訊息才算完成。
5. 回到 OmniKeep 按「我綁好了」，「已綁定的帳號」會多一個編號。

配對連結的規則（`app/bot/telegram_pairing.py`）：

- 產生後 10 分鐘內有效，只能用一次；畫面上會顯示幾點幾分前有效。
- 只在你和機器人的私人對話裡有效，在群組裡按沒有用。
- 機器人回覆「配對連結無效或已過期」時，回到 OmniKeep 再按一次「產生配對連結」。
- 綁定結果存進資料庫（App 設定 `TELEGRAM_ALLOWED_USER_IDS`），不寫 `.env`，不用重新啟動。
- 已經有擁有者時，新綁定的帳號會另外通知原本的擁有者。

沒有配對連結、也不在名單裡的人，傳什麼都不會被綁定，也不能使用機器人（舊版會把第一個傳訊息的人自動設為擁有者，已移除）。

### 其他做法

- **手動加入帳號編號**：還沒綁定的帳號傳任何訊息給機器人，它會回覆那個帳號的編號（User ID）。把這個數字填進「已綁定的帳號」的輸入框，按「加入」，再按「儲存」。
- **移除帳號**：在「已綁定的帳號」按該編號旁的移除鈕，再按「儲存」。儲存後那個帳號立刻不能再用機器人。

## 丟第一個連結

在 Telegram 把任何網址（網頁、YouTube、GitHub、社群貼文）或一段文字傳給機器人：

1. 機器人先回一則訊息，表示已經收到、正在處理。
2. 處理完，那則訊息會變成一張卡片，內容有：
   - 標題與分類
   - 摘要：一兩句白話說明這篇在講什麼
   - 標籤
3. 卡片下方的按鈕：
   - 加星／取消加星
   - 封存／取消封存
   - 展開重點分析（再按一次收合回摘要）
   - 開啟原始來源

同一則收藏也會出現在 OmniKeep 網頁的清單裡。

**還沒接上 AI 也能收藏。** 這時機器人回的卡片會註明已收藏、還沒有經過 AI 分析；網頁上這則收藏標示「尚未分析」。到「設定 › AI」接上 AI 連線後，會在背景自動補分析，也可以打開那則收藏按「現在分析」。

處理失敗時，卡片會顯示原因，並提供重試與刪除訊息的按鈕。

## 常用指令

| 指令 | 說明 |
| :--- | :--- |
| `/help` | 使用說明，也可以用來確認這個帳號已經綁定。 |
| `/mode [heartbeat\|quiet]` | 切換回覆方式：`heartbeat` 會在同一則訊息上更新處理進度；`quiet` 只提示已收到，完成時直接給卡片。 |
| `/stats` | 目前的收藏數量：未讀、加星、封存、總數。 |
| `/inbox` | 列出最近 5 則未讀的收藏，可以直接在手機上封存或加星。 |
| `/search [關鍵字]` | 搜尋收藏，例如 `/search OpenHands`。 |
| `/profile [內容]` | 檢視或更新興趣描述（AI 分析時會參考）。 |

下面幾個指令屬於實驗功能（預設關閉，在 設定 › 實驗功能 開啟），介面與行為還會改：

| 指令 | 說明 |
| :--- | :--- |
| `/deck` | 探索的逐則篩選：一則一則決定保留、加星、稍後或略過。 |
| `/proposals` | 檢視專案監看產生的建議，可以核准或忽略。 |
| `/dreampass` | 依最近的互動提議更新興趣描述，你同意才套用。 |

## 機器人怎麼執行

- **跟著主服務啟動（建議）**：只要存了機器人權杖，OmniKeep 啟動時（`python run.py`）就會一起啟動機器人，不用另外開程式。背景的分析工作和探索排程也在同一個程式裡。
- **分開部署（選用）**：想把機器人跑在另一台機器或另一個行程，才用 `python run_bot.py`。**兩邊同時跑會讓 Telegram 回 409 衝突（getUpdates 同時只能有一個）**，只能擇一。

## 遇到問題

| 狀況 | 怎麼處理 |
| :--- | :--- |
| 「產生配對連結」按不到，畫面寫要先儲存機器人權杖 | 先貼上權杖並按「儲存」。 |
| 按「測試機器人」失敗 | 確認複製的是 BotFather 給的整串權杖，中間沒有空白或換行。 |
| 開了配對連結，機器人沒有回應 | 確認有按「開始」；確認 OmniKeep 正在執行。 |
| 機器人回覆配對連結無效或已過期 | 連結超過 10 分鐘或已經用過，重新產生一個。 |
| 機器人回覆未授權 | 這個帳號不在「已綁定的帳號」裡，用配對連結綁定。 |
