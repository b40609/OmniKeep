# OmniKeep 公開發行檢查（2026-10-27）

此紀錄聚焦「第一次使用本專案的陌生使用者」，不代表已完成公開發布。公開前仍須檢查授權、歷史憑證與乾淨環境安裝。

## 已完成的本機準備

- 首次設定可由 `python scripts/bootstrap_env.py` 產生隨機強度足夠的 `API_KEY`，不覆寫既有 `.env`。
- 新安裝預設只綁定本機、關閉自動登入與自動情報掃描，並提供中性分類、停用狀態的範例情報來源。
- 快速開始優先介紹免 AI 的書籤匯入；需設定模型憑證時才啟用 AI 處理。
- 將歷史 QR 圖與文字版 QR 的內容替換為公開安裝文件網址，不再將開發者的裝置地址或認證參數交付到工作樹的新版本。
- 歷史手機測試頁改為自行輸入測試用 API Key，要求在 HTTP 標頭傳送，不將憑證放進 URL；主程式的靜態路由亦限制歷史頁面直接存取。
- 公開文件中已發現的開發機絕對路徑與舊範例設定改為可攜說明，補充手機安裝 PWA 的 HTTPS 條件。

## 公開前的必要決策與驗證

1. **歷史憑證與端點**：四張被 Git 追蹤的舊 QR 圖中，兩張原先包含認證參數，另兩張包含特定裝置／服務端點；歷史手機頁也曾含寫死的測試金鑰。它們在既有 Git commit 中仍可被還原。先檢查有關憑證是否仍有效，對可能有效的金鑰進行撤銷或輪換；評估遠端公開可見範圍與歷史紀錄處置。更新工作樹檔案**無法清除 Git 歷史**。任何歷史改寫、強制推送或刪檔都必須另外評估與授權。
2. **著作權與授權**：目前新增的 MIT 授權書使用 `OmniKeep contributors`；正式發布前確認授權所有權、第三方素材及依賴授權。
3. **真正全新安裝**：現有環境沒有 `docker` 執行檔，尚未完成乾淨主機 Docker Compose 建置、登入、匯入書籤、重啟保留資料的端到端驗收。
4. **公開內容校對**：README 與部分歷史文件含有功能、效能、PWA 與第三方整合描述；正式發布前逐項核對與實測，避免將環境依賴功能寫成開箱即用。

本輪未執行 Git commit／push、資料庫變更或任何歷史清理。任何現存使用者的設定與資料均應保留。
