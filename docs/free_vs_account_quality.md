# 免註冊與自己申請的差別（2026-11-18 實測）

全新安裝不用註冊就能用；差別攤開在「設定 › AI › 目前能用的功能」，使用者覺得值得再升級（2026-11-18 定案）。這份是那張卡上數字的出處。

## 每個功能用什麼

| 功能 | 免註冊時 | 升級做法 | 差多少 |
|---|---|---|---|
| 分析（摘要、剖析、GitHub 架構圖、標題） | flm → JarvisClaw → Kilo → OVHcloud | 免費的 Google AI Studio 金鑰，新增後自動排第 1 | 明顯，見下一節 |
| 提問、探索 | 沿用分析的清單 | 同上 | 跟分析一樣 |
| 用意思找收藏 | 沒有 Ollama 時用 OVHcloud 的 `Qwen3-Embedding-8B` | 裝 Ollama 和向量模型 | 準度一樣（第一名命中 0.853）；免註冊每分鐘只能查 2 次，見 [vector_index.md](vector_index.md) |
| 短影音畫面上的字 | JarvisClaw、OVHcloud 的 `Qwen3.6-27B` 看圖；flm、Kilo 不收圖片，不會送給它們 | Gemini | 小：簡單的文字圖兩家都讀對，真實影片畫面待驗證 |
| 長影片畫面上的字 | 本機 RapidOCR，安裝腳本會裝 | 不用升級 | 沒有差別 |
| 沒有字幕的影片轉文字 | 沒有 | `pip install -r requirements-stt.txt` | 沒裝就不能用 |
| 直接看 YouTube 影片 | 沒有，改讀字幕和畫面上的字 | Google AI Studio 的 Gemini，加到「影片」 | 只有 Gemini 能做 |

## 分析的盲評

- 樣本：18 篇已經用 Gemini 4 Hydrogen（Vertex）分析過的收藏，GitHub 專案 7 篇、文章 4 篇、YouTube 3 篇、Threads 2 篇、短影音 2 篇。
- 做法：同樣的提示詞和原文，交給免註冊的分析清單重跑（18 篇都由 flm 回答，4 到 83 秒）。GitHub 專案照正式流程檢查架構圖，畫錯的拿掉。兩份結果隨機標成 A、B，交給 Claude Sonnet 評：用別家模型當評審，避免 Gemini 偏袒自己的答案。
- 結果：Gemini 贏 17 篇，免註冊贏 1 篇（一篇文章）。

  | 平均分（1 到 5） | 正確 | 有用 | 文字 |
  |---|---|---|---|
  | Gemini | 4.72 | 4.61 | 4.50 |
  | 免註冊 | 3.78 | 3.50 | 3.39 |

- GitHub 架構圖：Gemini 6 篇都有，免註冊 7 篇只留下 3 張（另 1 張畫錯被拿掉）。深度分析長度中位數 Gemini 約 2,200 字，免註冊約 1,400 字，有一篇只有 50 字。
- 評審指出的免註冊問題：漏掉重點、偶爾有原文沒有的內容（把廣告寫成前置條件）、夾簡體字和中國用語。短內容（Threads、短影音）差距最小，GitHub 長 README 和長逐字稿差距最大。
- 限制：樣本只有 18 篇，評審只看得到原文前 3,500 字。

腳本與原始結果留在當時的暫存資料夾，沒有進 repo。
